# 🎓 Student Task Manager

## 📌 Project Description
Student Task Manager is a web application designed to help students manage their academic tasks, assignments, and deadlines easily.

This is an individual web development project built using HTML, CSS, Tailwind CSS, and JavaScript.

## 🎯 Project Objectives
- Organize academic tasks and assignments.
- Manage assignment deadlines.
- Set task priorities.
- Track completed and pending tasks.
- Improve student productivity.

## ✨ Features
- Add new tasks.
- Add subject names.
- Set assignment deadlines.
- Set priorities: High, Medium, and Low.
- Mark tasks as completed.
- Delete tasks.
- Search tasks by title or subject.
- Filter tasks by status.
- Track overdue assignments.
- View total, completed, pending, and overdue tasks.
- Display overall progress.
- Save tasks using LocalStorage.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Browser LocalStorage

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

**Note:** An internet connection is required to load Tailwind CSS from its CDN.
